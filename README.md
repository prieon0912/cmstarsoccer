# Floodlight Eleven

야간 경기장에서 즐기는 11대11 3D 축구 게임. 휴대폰 가로 모드에 맞춰 만들었습니다.

- 조작(FC Mobile 버튼 배치): 왼쪽 조이스틱으로 이동, 오른쪽 아래 큰 **질주** 버튼, 그 위 **슛**, 슛 왼쪽 **스루**, 질주 왼쪽 **패스**. 수비 때는 교체·압박·태클, 압박+질주를 같이 누르면 협력 수비.
- **패스**는 조이스틱이 가리키는 동료에게 가고, 누른 시간이 세기예요. 게이지의 흰 눈금이 알맞은 세기이고, 모자라면 느리게 굴러가 끊기기 쉽고 넘치면 받는 선수가 공을 흘려요(톡 치면 자동 세기). 패스를 누른 채 위로 밀었다 떼면 **롱패스**, 측면 깊은 곳과 코너킥에서는 **크로스**.
- **스루**는 달리는 동료와 공이 수비보다 먼저 만나는 지점을 계산해 찔러 주고, 누른 시간이 얼마나 앞으로 보낼지예요. 누른 채 위로 밀면 **로빙 스루**.
- **슛**은 길게 눌러 파워를 모으고, 떼기 전에 위로 밀면 칩슛, 아래로 감아차기, 오른쪽 파워 슛, 왼쪽 페이크 슛. 패스·스루·슛 게이지는 모두 같은 속도로 차요.
- **개인기**: 질주 버튼을 누른 채 위·아래·왼쪽·오른쪽으로 스와이프. 방향마다 넣을 기술은 전술 화면에서 13가지(라 크로케타 포함) 중 고릅니다. 선수마다 개인기 별(★1~5)이 있어 별이 모자라면 쉬운 기술이 나갑니다.
- **오프사이드**가 적용되고, 선수마다 숨은 성향(침투형·연결형, 공격/수비 가담, 압박 스타일 등)이 있어 움직임이 달라요. 전술 화면에서 선수를 누르면 성향 태그가 보여요.
- 경기 중 오른쪽 위 **AUTO**(키보드 T)를 누르면 컴퓨터가 대신 플레이하고, 다시 누르면 직접 조종으로 돌아옵니다(1인 경기만). 일시정지 메뉴에서 경기를 나가거나, 리그 경기는 기권(0:3 패배)할 수 있습니다.
- 키보드: WASD/방향키 이동, J 패스, U 롱패스·크로스, K 스루, I 로빙 스루, L/Space 슛, E 감아차기, R 칩슛, Shift 질주, 1~4 개인기, Q 협력 수비, C 카메라, P 일시정지.

## 프리미어리그 시즌

첫 화면이 리그 화면입니다. 처음 들어오면 시즌을 함께할 EPL 클럽을 고르고, 38라운드(홈·원정 각 19경기)를 치릅니다.

- **경기 시작**: 이번 라운드 내 경기를 직접 뜁니다. 끝나면 같은 라운드의 나머지 9경기는 클럽 전력(OVR)과 홈 이점으로 결과가 정해집니다.
- **결과만 보기**: 내 경기까지 포함해 라운드 전체를 시뮬레이션합니다.
- 순위표(챔피언스리그권·강등권 표시), 지난 라운드 결과·다음 일정, 득점 순위를 볼 수 있습니다.
- 시즌 기록과 클럽별 전술은 브라우저(localStorage)에 저장됩니다. **새 시즌**에서 클럽을 다시 고를 수 있습니다.
- **친선 경기**는 리그 기록과 상관없이 아무 두 팀이나 붙입니다.

선수 명단은 2025-26 시즌 개막 무렵 기준으로 적은 것이라 실제와 다를 수 있습니다. `public/index.html` 위쪽의 `CLUBS` 배열(클럽 이름·유니폼 색·포메이션·선발 11명 [이름, 등번호, 역할, OVR])을 고치면 바로 반영됩니다. 구단 엠블럼과 리그 로고는 넣지 않았고, 개인·비상업용으로만 쓰는 것을 전제로 합니다. 선수별 능력치(속도·슈팅·패스·드리블·수비·피지컬·개인기 별)는 바로 아래 `PSTAT_SRC` 표에 한 줄에 한 클럽씩 적혀 있어요. FC 시리즈 능력치 경향을 참고해 추정한 값이라 자유롭게 고쳐도 됩니다.

## 계정 · 내 팀 · 교체

- 메뉴의 **팀 설정**에서 계정을 만들면 모든 선수(20개 클럽 × 11명 = 220명)의 **베이스 카드**를 한 장씩 받아요. 고른 시작 클럽의 주전 11명으로 팀이 짜인 채로 시작해요.
- 경기장 자리나 교체 자리를 누른 다음 다른 자리를 누르면 서로 바뀌고, 오른쪽 카드 목록(검색·클럽·포지션 필터)을 누르면 그 선수가 들어가요. 교체 명단은 최대 7명.
- **단일팀 보너스**: 선발 11명이 모두 같은 클럽 카드면 모든 능력치 +3(OVR +3).
- 팀 이름·약칭·유니폼(어느 클럽 것이든)·포메이션·운영·**개인기 4방향 설정**도 팀 설정에서 바꿔요. 리그·친선 클럽용 전술 화면은 따로 남아 있어요.
- 계정은 브라우저(localStorage)에 저장돼요. 여러 계정을 만들 수 있고, **내보내기 코드**를 복사해 다른 기기에서 가져올 수 있어요.
- **친선 경기**에서 "★ 내 팀"을, **1대1 온라인**에서도 "★ 내 팀"을 고를 수 있어요(상대 브라우저로 팀 정보가 전달돼요). 프리미어리그 시즌은 지금처럼 고른 클럽으로 치러요.
- 경기 중 일시정지 → **선수 교체**: 경기당 최대 5명, 체력 막대를 보고 바꿔요. 나간 선수는 다시 못 들어와요. 온라인에서는 게스트의 교체 요청을 호스트가 처리해 양쪽에 똑같이 반영돼요.

## 1대1 온라인

리그 화면의 **1대1 온라인**에서 내 팀을 고른 뒤 빠른 매칭 또는 4자리 방 코드로 상대와 11대11 경기를 합니다. 각자 자기 팀의 선택된 선수를 조종하고 나머지는 AI가 움직입니다.

- 방을 만든 쪽(호스트) 브라우저가 경기를 계산하고, 상대(게스트)는 조작을 보내고 호스트가 보낸 화면 상태를 그립니다. 서버는 둘을 짝지어 메시지를 중계만 합니다.
- 게스트 화면은 뒤집어서 보여 주므로 두 사람 모두 자기 팀이 오른쪽으로 공격합니다.
- 배포된 서버(Render)에서 열었을 때만 동작합니다. `file://`나 claude.ai 아티팩트에서는 1인 모드만 됩니다.

## 구조

- `public/index.html` — 게임 전체 (three.js r128을 cdnjs에서 불러옴)
- `server.js` — Express로 `public/`을 서빙하고 `/ws`에서 1대1 매칭·중계(WebSocket)
- `render.yaml` — Render 배포 설정 (Blueprint)

## 선수 모델과 동작

- `public/assets/player.json` — three.js 예제의 X Bot(Mixamo) 모델을 약 1만 폴리곤으로 줄인 GLB를 base64로 담은 것. 유니폼·피부·머리색은 게임의 셰이더가 칠합니다.
- `public/assets/clips.json` — three.js 예제의 Soldier(걷기·달리기·대기)와 Michelle(삼바, 골 세리머니) 모션캡처 동작을 X Bot 골격에 맞게 변환한 것.
- 킥·다이빙·태클·슬라이딩·스로인 등 축구 동작은 코드에서 만든 자세를 같은 골격에 섞어 씁니다.
- 원본 모델과 동작은 Mixamo에서 나온 것으로 three.js 저장소(examples/models/gltf)에 포함된 파일입니다.

## 로그인 계정과 DB

- 서버(`server.js`)가 게임 파일, 1대1 중계(WebSocket), 로그인 API(`/api/...`)를 같이 맡아요.
- 아이디·비밀번호로 회원가입/로그인하면 팀·개인기가 Postgres에 저장돼서 어느 기기에서든 같은 팀으로 플레이해요. 비밀번호는 scrypt 해시로만 저장되고, 로그인은 60일짜리 토큰으로 유지돼요. 로그인 시도는 IP당 10분에 20번으로 제한돼요.
- 로그인 없이 쓰는 "이 기기 계정"(브라우저 저장)도 그대로 쓸 수 있어요.
- DB 연결은 환경 변수 `DATABASE_URL` 하나예요. 테이블(users, sessions, profiles)은 서버가 처음 켜질 때 알아서 만들어요. 값이 없으면 계정을 메모리에만 두고, 서버가 재시작되면 사라져요.

| API | 설명 |
|---|---|
| `POST /api/auth/register` | `{username, password, profile?}` → `{token, user, profile}` |
| `POST /api/auth/login` | `{username, password}` → `{token, user, profile}` |
| `POST /api/auth/logout` | 토큰 폐기 |
| `GET /api/me` | 내 정보와 저장된 팀 |
| `PUT /api/profile` | `{profile}` 저장 (최대 16KB) |
| `POST /api/me/delete` | `{password}` 확인 후 계정 삭제 |

## 로컬 실행

```
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/fl11 npm start   # http://localhost:3000
```

(`DATABASE_URL` 없이 `npm start`만 해도 돌아가요. 계정이 메모리에만 남을 뿐이에요.)

## 배포 (Render + Neon)

1. [Neon](https://neon.com)에서 무료 프로젝트를 만들고 **Connection string**(`postgresql://...?sslmode=require`)을 복사해요. Render 무료 Postgres는 30일 뒤 만료되니 Neon을 써요.
2. Render 대시보드 → **New → Blueprint** → 이 GitHub 저장소를 고르면 `render.yaml`대로 웹 서비스가 만들어져요. 이때 `DATABASE_URL`에 1번 값을 넣어요.
3. 이후 `main`에 푸시할 때마다 자동 배포돼요. `https://<서비스이름>.onrender.com/api/status`가 `"store":"postgres"`면 DB가 연결된 거예요.

Vercel이 아니라 Render를 쓰는 건 1대1 온라인이 WebSocket 서버를 계속 켜 둬야 해서예요(Vercel 함수는 WebSocket 서버를 못 띄워요). 무료 Render는 15분 동안 접속이 없으면 잠들고, 다시 깨는 데 1분쯤 걸려요.
